# Central de Provisioning

### Network Automation & Software Development

Aplicação desenvolvida para auxiliar operações de infraestrutura de redes, organizar procedimentos técnicos e facilitar atividades de provisionamento.

## Tecnologias

- HTML5
- CSS3
- JavaScript
- AutoHotkey v2
- Redes TCP/IP
- VLAN, BGP e QoS

## Funcionalidades

- Assistente de configuração BGP
- Alocação de portas
- Geração de comandos de rede
- Fluxos de ativação de clientes
- Histórico de operações
- Interface gráfica com tema escuro

## Objetivo

Unir desenvolvimento de software e engenharia de redes para criar ferramentas que facilitem operações técnicas.

## Status

Projeto em desenvolvimento. Versão pública demonstrativa em preparação.
